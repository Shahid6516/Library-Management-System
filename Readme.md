
# Library Management System

## Overview
A comprehensive system for managing library operations including book inventory, member management, and lending/returning processes.

## Features
- **Book Management**: Add, update, and remove books from inventory
- **Member Management**: Register and manage library members
- **Lending System**: Track book checkouts and returns
- **Search & Filter**: Find books and members efficiently
- **Reporting**: Generate usage and inventory reports

## Installation
```bash
# Clone the repository
git clone https://github.com/Shahid6516/Library-Management-System

# Install dependencies
npm install

# Start the application
npm start
```

## Usage
1. Launch the application
2. Add members through the Member module
3. Add books to inventory
4. Process lending and returns through the Lending module
5. Use search features to locate books or members

## Technologies
- **Frontend**: React
- **Backend**: Node js
- **Database** MongoDb
